Overview

This course introduces the principles and practices of software engineering, including requirements engineering, software architecture, design, implementation, testing, DevOps, and collaborative software development. Students should work on a semester long project utilzing the software engineering principles. The course also explores the role of generative AI in software engineering, including agentic coding, spec driven development, and AI-assisted testing.

Course Outline

Weeks 1–3: Foundations of Software Engineering
  • Software engineering principles and lifecycle models
  • Requirements engineering and user stories
  • Software architecture, design principles, UML, and design patterns
Weeks 4–6: Development Practices
  • Object-oriented design and principles
  • Git workflows, collaboration, code reviews
  • Clean code, refactoring, documentation, coding standards
Week 7: Generative AI for Software Engineering
  • Agentic coding and AI development environments
  • Spec driven development
Weeks 8–10: Testing, DevOps, and Quality
  • Software testing and AI-assisted test generation
  • CI/CD pipelines and deployment automation
  • Security, performance, and software quality assurance
Weeks 11–15: Project Development and Emerging Topics
  • Project management and agile development
  • Project midterm presentation (Week 9)
  • Final project integration and deployment
  • Emerging trends in software engineering and AI

Course Project

Overview

Teams should design, implement, test, and deliver a small software product over multiple iterations. You are expected to practice requirements elicitation, architectural design, version control, automated testing, and continuous integration. Weekly sprint reviews will track progress.

☁️ Spec Driven App Development As Available

The course project may leverage modern cloud and AI technologies to support software development, deployment, and experimentation. Students may use Google Cloud Platform services such as Cloud Run, Gemini Enterprise Agent Platform and others, subject to available cloud credits.

Milestones

  1. Project Proposal & Requirements (Week 3)
  2. Architecture & Initial Prototype (Week 5)
  3. Iteration 1 — Core Features + Tests (Week 8)
  4. Iteration 2 — Extensions + CI (Week 11)
  5. Final Demo & Report (Week 14)

Deliverables

  • Team repo (GitHub) with Issues/Boards
  • Design document (architecture & rationale)
  • Automated test suite & CI configuration
  • Demo video (5–7 min) + Final report

Overview

What this course is about

This course covers data mining and machine learning algorithms for analyzing large-scale datasets. The primary focus is on MapReduce and Apache Spark as frameworks for designing parallel algorithms that efficiently process massive datasets — from similarity search across billions of items to ranking and community structure in graphs with millions of nodes.

Along the way: the linear algebra that underlies it, the hashing tricks that make similarity search tractable at scale, and the streaming techniques needed when data arrives faster than it can be stored.

Schedule

Fifteen weeks, six modules

The syllabus moves from foundations to distributed frameworks, then through similarity search, dimensionality reduction, graph analytics, and finally scale & streaming — each module building on the one before it.

Module 01

Foundations

Setting up the math and mental models behind large-scale data processing.

  • W01Introduction; Linear Algebra Refresher
Module 02

Distributed Frameworks

The two engines that make cluster-scale computation possible.

  • W02MapReduce
  • W03Apache Spark
Module 03

Similarity & Hashing

Finding near-duplicates and similar items without comparing every pair.

  • W04Locality Sensitive Hashing — Part 1
  • W05Locality Sensitive Hashing — Part 2
  • W06Locality Sensitive Hashing — Part 3
Module 04

Dimensionality Reduction

Compressing high-dimensional data down to what actually matters.

  • W07Dimensionality Reduction — Part 1
  • W08Dimensionality Reduction — Part 2
Module 05

Graph Analytics

Ranking, recommending, and finding structure in networks at scale.

  • W09Graph Analytics
  • W10PageRank
  • W11Extensions of PageRank to Recommendations and Spam
  • W12Community Detection in Graphs
Module 06

Scale, Streams & Presentations

Learning from data too big to store, too fast to wait for — then presenting what you built.

  • W13Large Scale Machine Learning
  • W14Mining Data Streams
  • W15Project Presentations

Course Project

Built on Google Cloud

The course project involves BigQuery, a managed service for Apache Spark, the Gemini Enterprise agent platform, Compute Engine, GKE, and Cloud Run — contingent on available cloud credits.

BigQuery

Serverless data warehouse for querying massive datasets with SQL.

Managed Spark

Apache Spark as a managed service — no cluster to provision by hand.

Gemini Enterprise

Agent platform for building AI-driven data workflows.

Compute Engine

Configurable virtual machines for custom workloads.

GKE

Managed Kubernetes for containerized, distributed jobs.

Cloud Run

Serverless containers that scale to zero between jobs.
